# ADR-0001: Границы диплома и трактовка требований

**Статус:** Accepted
**Дата:** 2026-10-27
**Обновлено:** 2026-11-04 (срок сдвинут на лето 2027, уточнён backend)

## Контекст
Исходный список пожеланий содержал 10+ направлений и несколько неоднозначных
формулировок. Для диплома важнее глубина и доказательность, чем ширина.
Защита — летом 2027, то есть ~30 недель с ноября 2026.

## Решения
1. **Объём:** 6 блоков R1–R6 + сквозной R7 (UX/тесты/текст/демо). Летний срок
   позволяет пройти все блоки и добавить push/эксперименты; scope не расширяем
   без ADR.
2. **«Разные страны»:** только глобальный поиск (геокодинг/маршрутизация в любой
   стране). UI остаётся ru/en; новые языки не входят.
3. **«Второй режим расстояния»:** трактуется как **«куда можно пойти после
   выбранного заведения»** — подбор следующего шага и маршрут между шагами.
   Это не второй режим радиуса поиска.
4. **«ИИ-помощник»:** только **консьерж подбора** (формат/место/следующий шаг).
   Бот в чате не входит в объём.
5. **Приватные комнаты:** остаются на 2 участника. Multi-user — только открытые
   сессии.
6. **Backend:** AI и push требуют серверного компонента. Решение по нему —
   ворота G1 (2026-11-17). Выбран **внешний прокси** (Node/Fastify), потому что
   Cloud Functions требуют Blaze, а Беларуси нет в списке стран Cloud Billing.
   Firebase остаётся на Spark; Cloud Functions — резервный вариант.
7. **Публичные API:** Nominatim/Overpass/OSRM используются с кэшем и fallback;
   отсутствие SLA — документированное ограничение.

## Последствия
- Все 6 блоков, но каждая фича с теорией, тестами и замером.
- Схема комнаты v2 — критический путь; chat/форматы/открытые сессии после неё.
- Push может остаться local-only, если не будет backend; это фиксируется в тексте.
- AI без серверного прокси не делаем (ключ в клиенте недопустим).

- Roadmap и ворота G1–G7 согласованы.
